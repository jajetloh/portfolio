QuokkaSim

Code (Rust)

A Rust framework for building efficient, accessible and sustainable Process Simulation models. QuokkaSim is zero-cost and Open Source, and combines the benefits of Rust's compile-time checks, the efficiency of nexosim runtime, and the minimal memory footprint of binaries compiled from Rust.

TTGen

Code (Python)

Highly efficient Python package for generating combinations of sets with duplicates (a.k.a. multisets), with exponential speed-up compared to the default Python implementation for multisets with high multiplicity. Based on O(1) Time Generation of Adjacent Multiset Combinations by Tadao Takaoka.
