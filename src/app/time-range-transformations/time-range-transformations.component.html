Intro

Polars is fast becoming one of my favourite Python packages to use. It offers itself as a new but hard-hitting competitor to Pandas, the de-facto data table library for Python since 2008, spruiking features like built-in parallelisation, query optimisation, significant performance improvements over Pandas, strict typing and immutability for columns - to name its most impressive qualities thus far.
After hearing the pitch and trying the library in my own work instead of Pandas, I was sold. The next step, was to get the people I work with on board as well, and this is a bit more tricky. Introducing a new package to a team - especially one which attempts to be a replacement for an existing package, can invoke a healthy amount of scepticism. Great that it's selling us these improvements over what we already use, but what about the many other considerations we need to take that aren't Polars' selling points?
